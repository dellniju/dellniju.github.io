# دلني — خريطة الجامعة الأردنية

إذا تايه… بْدِلَّك. موقع خريطة وإرشاد مشي داخل حرم الجامعة الأردنية.

- البحث عن أي كلية، مبنى، قسم، كافيه أو بوابة، والتوجيه بالمشي
- البحث برقم القاعة وفتح مخطط المبنى على الطابق الصحيح
- مساعد "اسأل دلني" يعمل بدون إنترنت
- "محاضراتي" (اختياري من القائمة ☰): يذكّرك وين محاضرتك الجاية وكم بدك مشي
- روابط للمشاركة، فلترة الخريطة حسب التصنيف، ووضع داكن

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الموقع كامل |
| `favicon.png` | أيقونة الموقع في تبويب المتصفح |
| `.github/workflows/static.yml` | ينشر الموقع على GitHub Pages تلقائياً مع كل تحديث |

## روابط المشاركة

- `?to=law` — يفتح الطريق إلى كلية الحقوق
- `?to=law&from=main_gate` — من البوابة الرئيسية
- `?hall=104&b=geology` — يفتح القاعة 104 على المخطط
- `?plan=science_complex` — مخطط مبنى
- `?place=zaza` — يعرض المكان على الخريطة
